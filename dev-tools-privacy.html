Privacy Policy for DevTools XT

Last updated: May 8, 2026

DevTools XT is a browser extension that provides web development and inspection tools. This policy explains what data the extension handles and how it is used.

Information We Collect

DevTools XT does not collect personal information for sale or advertising.

  • Extension settings and preferences are stored locally in your browser.
  • Tool state and history are stored locally to support extension features.
  • No account, login, or identity data is required to use the extension.

How Data Is Used

  • To enable extension functionality on pages you choose to inspect.
  • To remember your selected tool options and interface preferences.
  • To perform user-requested actions, such as clearing browser data.

Browser Permissions

DevTools XT requests permissions only to provide development features:

  • scripting / tabs / host access: run tools in the current page context.
  • side panel: display the extension interface.
  • storage: save local settings and preferences.
  • web navigation: identify frame context (including iframes).
  • browsing data: clear cache, cookies, and local data when you trigger it.

Data Sharing

DevTools XT does not sell your personal data and does not share your data with third parties for marketing purposes.

Data Retention and Control

  • Most extension data remains local in your browser profile.
  • You can clear extension data by removing the extension or clearing browser storage.
  • You control when the extension runs and when optional actions are performed.

Changes to This Policy

This privacy policy may be updated over time. Changes will be reflected by updating the "Last updated" date on this page.
